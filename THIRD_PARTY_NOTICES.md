# Third-party components

The desktop distribution includes Python, PySide6/Qt, Shiboken and pyserial.
These components retain their own copyrights and licenses, independently of
this repository's copyright status. PyInstaller is a build-time tool.

| Component | Source / license information |
|---|---|
| Python | https://www.python.org/psf/license/ |
| PySide6 and Shiboken | https://code.qt.io/cgit/pyside/pyside-setup.git/ |
| Qt | https://www.qt.io/licensing/ |
| pyserial | https://github.com/pyserial/pyserial |
| PyInstaller | https://github.com/pyinstaller/pyinstaller |

The ESP32 firmware depends on the Arduino ESP32 core, LittleFS and Mbed TLS
provided by the board package. Their upstream licenses continue to apply.
Binary distribution must include the notices shipped with those components.
